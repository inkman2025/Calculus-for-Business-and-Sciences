Functions: The Language of Change

The Business Question

A coffee shop owner wants to know: if she raises the price of a latte by $1, what happens to her daily revenue? If a manufacturer increases production by 100 units, how much does total cost increase? If a city's population grows at 3% per year, what will it be in ten years?

Every one of these questions is a question about a function — a rule that connects an input quantity to an output quantity. Before we can measure how things change (calculus), we must be able to describe what things are (functions). This chapter builds that language precisely and completely.

Everything in this course rests on a single foundational concept: the function. A function is not a formula. It is not a graph. It is not a table. It is something more fundamental than any of these representations: it is a relationship between quantities, a rule that assigns to each input exactly one output. The formula, the graph, the table — these are ways of seeing a function. The function itself is the relationship.

This distinction matters. When a business analyst says “revenue depends on the number of units sold,” they are describing a function. When a pharmacist says “drug concentration depends on time since administration,” they are describing a function. When you say “if I know \(x\), I can determine \(y\),” you are describing a function. The language of calculus is the language of how functions change, and it begins here.

1.1 What Is a Function?

Definition

Function

A function \(f\) is a rule that assigns to each input value \(x\) in a set called the domain exactly one output value, written \(f(x)\), in a set called the range.

We write \(y = f(x)\) and read this as “\(y\) equals \(f\) of \(x\).”

  • \(x\) is the independent variable (the input)
  • \(y\) is the dependent variable (the output)
  • \(f\) is the name of the function (the rule itself)

The one-output requirement is not negotiable. A rule that assigns two different outputs to the same input is not a function.

Why “exactly one” output? In business, if you tell someone a product's price and they can't determine the resulting revenue without additional information, revenue is not a function of price alone. Functions are relationships where the output is determined by the input — no ambiguity, no choice.

Four Ways to Represent a Function

A function can be described in four equivalent ways. Each reveals something different about the relationship.

Representation What it looks like Best for
Verbal“Revenue equals price times quantity sold.”Understanding meaning and context
Numerical (table)A table of input-output pairsEstimating values; computing rates of change
GraphicalA curve or set of points on coordinate axesSeeing behavior: increasing, decreasing, peaks
Algebraic (formula)\(R(q) = 50q - 0.5q^2\)Exact computation; calculus

All four representations describe the same function. The formula is often the most precise, but the graph and table are often the most revealing. We will move fluently among all four throughout this course.

The Vertical Line Test

When a function is represented as a graph, there is a simple visual test for whether it truly is a function:

Key Result

The Vertical Line Test

A graph represents a function if and only if every vertical line intersects the graph at most once.

Reason: A vertical line at \(x = a\) represents the question “what is the output when the input is \(a\)?” If the vertical line hits the graph twice, then there are two outputs for the same input — violating the definition of a function.

1.2 Domain and Range

Definition

Domain and Range

The domain of a function is the set of all allowable input values \(x\).

The range of a function is the set of all possible output values \(f(x)\) that result from inputs in the domain.

In pure mathematics, the domain is usually all real numbers for which the formula is defined. In business and economics, the domain is constrained by context — and that constraint often matters more than the algebra.

Example 1.1 Identifying Domain from Context

A company produces and sells \(q\) units of a product. The revenue function is \(R(q) = 80q - 2q^2\).

Base Camp

Schema Navigation

Step 1 — What is the input and output? The input is \(q\) (units produced and sold). The output is \(R\) (revenue in dollars).

Step 2 — What values of \(q\) make sense? We ask: can the company produce a negative number of units? No. Can it produce a fraction of a unit? In many settings, no — but for our purposes we allow it.

Step 3 — State the domain. The domain is \(q \geq 0\), or in interval notation: \([0, \infty)\).

Honest annotation: A Base Camp student correctly identifies that \(q\) cannot be negative. The range requires more work (finding the maximum), so we stop here and note what we know: revenue starts at \(R(0) = 0\) and increases initially as more units are sold.

Mid-Mountain

Schema Navigation

Step 1 — Input, output, units. \(q\) = units produced (input); \(R(q)\) = revenue in dollars (output).

Step 2 — Domain from context. \(q \geq 0\) (can't produce negative units). Also: \(R(q) \geq 0\) requires \(80q - 2q^2 \geq 0 \Rightarrow 2q(40-q) \geq 0 \Rightarrow q \in [0, 40]\). Beyond \(q = 40\), revenue becomes negative (price would have to be negative), which makes no economic sense. So the practical domain is \([0, 40]\).

Step 3 — Range. On \([0,40]\), the maximum revenue occurs at \(q = 20\) (vertex of the parabola): \(R(20) = 80(20) - 2(400) = 1600 - 800 = \$800\). The range is \([0, 800]\).

Interpretation: This firm can generate between $0 and $800 in revenue depending on how many units it produces, with maximum revenue achieved at 20 units.

Summit

Schema Navigation

Step 1 – Full identification. \(q\) = quantity (units); \(R(q) = 80q - 2q^2\) = revenue ($). This is a downward parabola — a quadratic function with negative leading coefficient.

Step 2 — Domain analysis. Mathematical domain: all real \(q\) where \(R\) is defined — all of \(\mathbb{R}\). Economic domain: \(q \geq 0\) (non-negative production). Practical domain: \(q \in [0,40]\) since \(R(q) < 0\) for \(q > 40\), which has no economic meaning.

Step 3 — Range and behavior. \(R(q) = -2(q^2 - 40q) = -2(q-20)^2 + 800\). Maximum revenue: \(\$800\) at \(q = 20\). Range on \([0,40]\): \([0, 800]\).

Step 4 — Connection to the demand function. Revenue = price \(\times\) quantity, so \(R(q) = p(q)\cdot q\). This means \(p(q) = R(q)/q = 80 - 2q\), which is the implied linear demand function. At \(q = 0\): price is $80 (market price with no output). At \(q = 40\): price is $0 (demand has been fully exhausted).

Insight: The domain constraint \(q \in [0,40]\) is not an algebraic accident — it is an economic reality. Revenue functions always have natural upper bounds from market demand.

1.3 Linear Functions

Definition

Linear Function

A linear function has the form \[f(x) = mx + b\] where \(m\) is the slope and \(b\) is the \(y\)-intercept.

The slope \(m\) represents the constant rate of change: for every one-unit increase in \(x\), the output \(f(x)\) changes by exactly \(m\) units.

The slope is the most important number in a linear function. Its sign tells you everything about direction:

Slope: The Rate of Change

For a linear function \(f(x) = mx + b\), the slope is: \[m = \frac{\Delta y}{\Delta x} = \frac{f(x_2) - f(x_1)}{x_2 - x_1} \quad\text{for any two points }(x_1, f(x_1))\text{ and }(x_2, f(x_2))\]

The units of slope are always: \(\dfrac{\text{[units of output]}}{\text{[units of input]}}\)

Example 1.2 Interpreting Slope in a Business Context

A company's total cost function is \(C(q) = 25q + 400\), where \(q\) is units produced and \(C\) is cost in dollars.

Base Camp

Schema Navigation

Step 1 — Identify the function type. \(C(q) = 25q + 400\) is linear: it has the form \(mx + b\) with \(m = 25\) and \(b = 400\).

Step 2 — Identify the slope and intercept. Slope: \(m = 25\). \(y\)-intercept: \(b = 400\).

Step 3 — State what each means. The slope \(m = 25\) means cost increases by $25 for each additional unit produced. The intercept \(b = 400\) means even at \(q = 0\) (no production), cost is $400.

Annotation: I recognize the structure and can identify the numbers. The slope tells me about variable cost per unit; the intercept is the fixed cost.

Mid-Mountain

Schema Navigation

Step 1 — Identify and classify. \(C(q) = 25q + 400\): linear, with slope \(= 25\) $/unit and intercept \(= 400\) $.

Step 2 — Economic interpretation of each component.

  • Slope = 25 $/unit: This is the variable cost per unit (also called the marginal cost for a linear cost function). Each additional unit adds $25 to total cost, regardless of how many units have been produced.
  • Intercept = $400: This is the fixed cost — the cost incurred even when \(q = 0\). It includes rent, equipment, and other costs that do not depend on production volume.

Step 3 — Compute specific values. \(C(0) = \$400\) (fixed cost alone)
\(C(10) = 25(10)+400 = \$650\) (cost of producing 10 units)
\(C(50) = 25(50)+400 = \$1{,}650\) (cost of producing 50 units)

Step 4 — Interpret the slope as a rate. Going from \(q=10\) to \(q=50\): \(\Delta C = 1650 - 650 = \$1{,}000\) over \(\Delta q = 40\) units. Rate \(= \$1000/40 = \$25\)/unit. ✓

Summit

Schema Navigation

Step 1 — Full classification and structure. \(C(q) = 25q + 400\). Linear function; slope \(= 25\) $/unit; intercept \(= 400\) $. This is a total cost function with structure: Total Cost = Variable Cost + Fixed Cost, i.e., \(C(q) = VC(q) + FC = 25q + 400\).

Step 2 — Average cost analysis. Average cost per unit: \(AC(q) = C(q)/q = 25 + 400/q\). As \(q\) increases, \(AC(q)\) decreases (the fixed cost is spread over more units) and approaches $25 asymptotically. This is economies of scale from fixed cost dilution.

Step 3 — Revenue and profit connection. Suppose the product sells for \(p = \$60\) per unit. Then: \(R(q) = 60q\) and \(\pi(q) = R(q) - C(q) = 60q - 25q - 400 = 35q - 400\).

Break-even: \(\pi(q^*) = 0 \Rightarrow 35q^* = 400 \Rightarrow q^* \approx 11.4\) units. The firm needs to produce and sell at least 12 units to be profitable.

Step 4 — Graphical insight. The profit function is also linear with slope \(35\) $/unit and intercept \(-400\). The slope of \(\pi\) equals the slope of \(R\) minus the slope of \(C\): \(60 - 25 = 35\). This makes sense: each unit sold adds $60 in revenue and costs $25, netting $35 in profit.

1.4 Increasing and Decreasing Functions

One of the most important things we can say about a function is whether it is going up or going down over a given interval. This language must be precise.

Definition

Increasing and Decreasing on an Open Interval

A function \(f\) is increasing on an open interval \((a, b)\) if: \[x_1 < x_2 \;\text{ in } (a,b) \;\Longrightarrow\; f(x_1) < f(x_2)\]

A function \(f\) is decreasing on an open interval \((a, b)\) if: \[x_1 < x_2 \;\text{ in } (a,b) \;\Longrightarrow\; f(x_1) > f(x_2)\]

Why open intervals? We say \((a,b)\), not \([a,b]\), because at the endpoints themselves the function may be changing direction. Saying a function is increasing on \((a,b)\) means it is going up strictly between \(a\) and \(b\) — we make no claim about what happens at \(a\) or \(b\) exactly. This becomes critical when we study derivatives in Chapter 5.

This function is:

  • Increasing on \((0, 1)\) and \((4, 6)\)
  • Decreasing on \((1, 4)\)

1.5 Business Functions: Demand, Cost, Revenue, Profit

Four functions are the foundation of every economic analysis in this book. You will see them in every chapter. Know them cold.

Concept

The Four Core Business Functions

Let \(q\) = quantity produced and sold (units), \(p\) = price per unit ($).

Function Notation Meaning
Demand\(p = D(q)\)Price at which consumers demand \(q\) units. Typically decreasing: higher quantity \(\Rightarrow\) lower price.
Cost\(C(q)\)Total cost to produce \(q\) units. Usually \(C(q) = FC + VC(q)\) where \(FC\) = fixed cost, \(VC\) = variable cost.
Revenue\(R(q) = p\cdot q = D(q)\cdot q\)Total revenue from selling \(q\) units at price \(p = D(q)\).
Profit\(\pi(q) = R(q) - C(q)\)Net gain. Positive \(\Rightarrow\) firm makes money. Negative \(\Rightarrow\) firm loses money.

Break-even quantity: the value of \(q\) where \(\pi(q) = 0\), i.e., where \(R(q) = C(q)\).

Example 1.3 Building the Core Business Functions

A small manufacturer faces a linear demand function \(p = D(q) = 100 - 2q\) (price in $/unit, quantity in units). Fixed costs are $300; variable cost is $10 per unit. Build all four core business functions and find the break-even quantities.

Base Camp

Schema Navigation

Step 1 — Identify what's given. Demand: \(p = 100 - 2q\). Fixed cost: $300. Variable cost: $10/unit.

Step 2 — Build Cost. \(C(q) = \text{fixed} + \text{variable} = 300 + 10q\)

Step 3 — Build Revenue. \(R(q) = p\cdot q = (100 - 2q)\cdot q = 100q - 2q^2\)

Step 4 — I recognize I need Profit next, but let me first check my work. At \(q=0\): \(R(0) = 0\) ✓ (no sales, no revenue). At \(q=0\): \(C(0) = 300\) ✓ (fixed costs remain).

Honest annotation: I built \(C\) and \(R\) correctly. Profit requires subtracting, and finding break-even requires solving an equation — those are the next steps.

Mid-Mountain

Schema Navigation

Step 1 — Identify and label all given information. \(D(q) = 100-2q\) ($/unit); \(FC = \$300\); \(VC = \$10\)/unit.

Step 2 — Build all four functions. \[\begin{aligned} C(q) &= 300 + 10q \quad\text{(\$ total cost)} \\ R(q) &= D(q)\cdot q = (100-2q)q = 100q - 2q^2 \quad\text{(\$ revenue)} \\ \pi(q) &= R(q) - C(q) = 100q - 2q^2 - 300 - 10q = -2q^2 + 90q - 300 \end{aligned}\]

Step 3 — Find break-even quantities. Set \(\pi(q) = 0\): \[-2q^2 + 90q - 300 = 0 \;\Rightarrow\; 2q^2 - 90q + 300 = 0 \;\Rightarrow\; q^2 - 45q + 150 = 0\] Using the quadratic formula: \[q = \frac{45 \pm \sqrt{2025 - 600}}{2} = \frac{45 \pm \sqrt{1425}}{2} \approx \frac{45 \pm 37.75}{2}\] So \(q \approx 41.4\) or \(q \approx 3.6\).

Step 4 — Interpret. The firm breaks even at approximately \(q = 3.6\) units (entering profitability) and \(q = 41.4\) units (exiting profitability). Between these quantities, the firm is profitable. The practical production range is \(q \in [4, 41]\) (whole units).

Summit

Schema Navigation

Step 1 — Full setup. \(D(q)=100-2q\); \(C(q)=300+10q\); \(R(q)=100q-2q^2\); \(\pi(q)=-2q^2+90q-300\).

Step 2 — Break-even and profit-maximizing quantities. Break-even: \(q \approx 3.6\) and \(q \approx 41.4\) (from Mid-Mountain).

Profit is a downward parabola. Its maximum occurs at the vertex: \(q^* = -\frac{b}{2a} = -\frac{90}{2(-2)} = \frac{90}{4} = 22.5\) units. Maximum profit: \(\pi(22.5) = -2(22.5)^2 + 90(22.5) - 300 = -1012.5 + 2025 - 300 = \$712.50\).

Step 3 — Analysis of increasing/decreasing behavior. \(\pi(q) = -2q^2+90q-300\) is a downward parabola:

  • Increasing on \((0,\,22.5)\): each additional unit adds to profit
  • Decreasing on \((22.5,\,\infty)\): each additional unit reduces profit
  • Maximum profit of $712.50 at \(q = 22.5\) units

Step 4 — Graphical synthesis.

Business insight: The profit-maximizing quantity (22.5 units) is not at the midpoint of the break-even interval, and it is not where revenue is maximized. Revenue peaks at \(q = 25\) (where \(R'(q)=0\)), but the additional units from 22.5 to 25 cost more to produce than they generate in marginal revenue. We will prove this rigorously using derivatives in Chapter 9.

1.6 Exponential Functions

Linear functions change by adding a fixed amount each period. But many real-world quantities — populations, investments, drug concentrations, radioactive isotopes — change by multiplying by a fixed factor each period. A bank balance that grows by 6% per year is not adding $6 each year; it is multiplying by \(1.06\) each year. This is exponential behavior, and it requires a fundamentally different function family.

Definition

Exponential Function

An exponential function has the form \[f(x) = a^x, \quad a > 0, \; a \neq 1\] where \(a\) is the base and \(x\) is the exponent (the input variable).

\(a > 1\):exponential growth — \(f\) increases as \(x\) increases
\(0 < a < 1\):exponential decay — \(f\) decreases as \(x\) increases

More generally, with an initial value \(Q_0\) and growth factor \(a\) per period: \[Q(t) = Q_0 \cdot a^t\] The output \(Q\) is multiplied by \(a\) for each one-unit increase in \(t\).

The Key Difference: Linear vs. Exponential

Property Linear \(f(x)=mx+b\) Exponential \(f(x)=Q_0 a^x\)
Change per periodAdds \(m\) (constant amount)Multiplies by \(a\) (constant ratio)
Identifies from dataConstant differencesConstant ratios
GraphStraight lineCurved (J-curve or decay)
Long-run behaviorGrows/falls without boundExplosive growth or approaches 0

Both functions start at the same value. The linear function grows steadily. The exponential function eventually dominates overwhelmingly — a pattern that appears in compounding interest, viral growth, and unchecked population expansion.

1.7 The Natural Base \(e\) and Continuous Growth

Any exponential function \(Q_0 a^t\) can be written in terms of a single special base: the number \(e \approx 2.71828\).

Definition

The Natural Base \(e\) and Continuous Growth Rate

The number \(e \approx 2.71828\ldots\) is defined as: \[e = \lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n\] It is the base that arises naturally from continuous compounding. Any exponential \(Q_0 a^t\) can be rewritten as: \[Q(t) = Q_0\,e^{kt}, \qquad \text{where } k = \ln a\] The constant \(k\) is called the continuous growth rate:

  • \(k > 0\): continuous exponential growth
  • \(k < 0\): continuous exponential decay

Why \(e\) matters in finance: If a bank compounds interest \(n\) times per year at annual rate \(r\), the balance after one year is \(P(1+r/n)^n\). As \(n\to\infty\) (compounding every instant), this becomes \(P\,e^r\) — continuous compounding. This is why \(e\) is the natural base for all financial mathematics.

Compound Interest Formulas

Key Result

Compound Interest

Compounded \(n\) times/year:\(A = P\!\left(1+\dfrac{r}{n}\right)^{nt}\)
Compounded continuously:\(A = P\,e^{rt}\)

where \(P\) = principal, \(r\) = annual interest rate (decimal), \(t\) = years, \(A\) = amount after \(t\) years.

Example 1.4 Comparing Compounding Frequencies

$5,000 is invested at 8% annual interest for 10 years. Compare annual, quarterly, monthly, and continuous compounding.

Base Camp

Schema Navigation

Step 1 — Identify formula and values. \(P=5000\), \(r=0.08\), \(t=10\).

Annual compounding (\(n=1\)): \(A = 5000(1.08)^{10} = 5000(2.1589) = \mathbf{\$10{,}794.62}\)

Continuous compounding: \(A = 5000\,e^{0.08\times 10} = 5000\,e^{0.8} = 5000(2.2255) = \mathbf{\$11{,}127.70}\)

Annotation: Continuous compounding earns $333 more than annual over 10 years. More frequent compounding always earns more.

Mid-Mountain

Schema Navigation

Compounding\(n\)Balance after 10 yr
Annual1$10,794.62
Quarterly4$11,040.20
Monthly12$11,098.20
Continuous\(\infty\)$11,127.70

Diminishing returns: Annual\(\to\)quarterly gains $246; quarterly\(\to\)monthly gains $58; monthly\(\to\)continuous gains only $30. The benefit of more frequent compounding diminishes rapidly.

Effective annual rate (continuous): \(e^{0.08}-1 \approx 8.33\%\). The nominal 8% continuously compounded is equivalent to 8.33% compounded annually.

Summit

Schema Navigation

Doubling time via the Rule of 72.

At what time does the investment double? \(P\,e^{rt}=2P \Rightarrow e^{rt}=2 \Rightarrow t=\ln 2/r\). At \(r=8\%\): \(t=\ln 2/0.08=0.6931/0.08=8.66\) years.

Rule of 72: Doubling time \(\approx 72/r\%\). At 8%: \(72/8=9\) years. The exact answer (8.66 yr) shows it slightly overestimates.

\[\begin{array}{c|c|c} r & \text{Exact doubling time} & \text{Rule of 72} \\\hline 4\% & 17.3 \text{ yr} & 18 \text{ yr} \\ 6\% & 11.6 \text{ yr} & 12 \text{ yr} \\ 8\% & 8.7 \text{ yr} & 9 \text{ yr} \\ 12\% & 5.8 \text{ yr} & 6 \text{ yr} \end{array}\]

Investment insight: At 8% continuously compounded, $5,000 doubles every 8.66 years — becoming $10,000, $20,000, $40,000 at years 8.66, 17.3, and 26. This is the compounding effect that makes long-horizon investing so powerful.

1.8 The Natural Logarithm

Definition

The Natural Logarithm \(\ln x\)

The natural logarithm \(\ln x\) is the inverse of \(e^x\): \[\ln(e^x) = x \quad \text{for all } x \qquad\qquad e^{\ln x} = x \quad \text{for all } x > 0\] \(\ln x\) asks: “to what power must \(e\) be raised to produce \(x\)?”

Key values: \(\ln 1 = 0\); \(\ln e = 1\); \(\ln x\) is undefined for \(x \leq 0\).

Logarithm rules: \[\ln(AB) = \ln A + \ln B \qquad \ln\!\left(\frac{A}{B}\right) = \ln A - \ln B \qquad \ln(A^p) = p\ln A\]

Key Result

Solving Exponential Equations with \(\ln\)

To solve \(e^{kt} = b\) for \(t\): \[e^{kt} = b \;\xrightarrow{\;\ln\text{ both sides}\;}\; kt = \ln b \;\xrightarrow{\;\div k\;}\; t = \frac{\ln b}{k}\] This is the essential algebraic step for any threshold or timing problem involving exponential functions.

The graphs of \(e^x\) and \(\ln x\) are mirror images across the line \(y=x\) — the visual signature of inverse functions.

1.9 Exponential Growth and Decay: Applications

Concept

The Exponential Model \(Q(t) = Q_0\,e^{kt}\)

Finding \(k\) from two data points:\(k = \dfrac{\ln(Q_2/Q_1)}{t_2 - t_1}\)
Doubling time (\(k>0\)):\(t_d = \dfrac{\ln 2}{k} \approx \dfrac{0.693}{k}\)
Half-life (\(k<0\)):\(t_{1/2} = \dfrac{\ln 2}{|k|} \approx \dfrac{0.693}{|k|}\)
When does \(Q\) reach target \(T\)?\(Q_0\,e^{kt}=T \;\Rightarrow\; t = \dfrac{\ln(T/Q_0)}{k}\)
Example 1.5 Population Growth

A city's population was 85,000 in 2010 and 102,000 in 2020. Assume continuous exponential growth. Predict the 2030 population and find when the population will reach 150,000.

Base Camp

Schema Navigation

Step 1 — Set up the model. \(P(t) = 85{,}000\,e^{kt}\), \(t\) = years since 2010.

Step 2 — Find \(k\). \(P(10)=102{,}000\): \[85{,}000\,e^{10k}=102{,}000 \;\Rightarrow\; e^{10k}=1.2 \;\Rightarrow\; k=\frac{\ln 1.2}{10}=\frac{0.1823}{10}\approx 0.01823\]

Step 3 — Predict 2030 (\(t=20\)): \(P(20)=85{,}000\,e^{0.3646}\approx 85{,}000(1.440)\approx\mathbf{122{,}400}\) people.

Mid-Mountain

Schema Navigation

\(P(t)=85{,}000\,e^{0.01823t}\) (continuous growth rate \(\approx 1.82\%\)/yr).

When does \(P\) reach 150,000? \[85{,}000\,e^{0.01823t}=150{,}000 \;\Rightarrow\; t=\frac{\ln(150{,}000/85{,}000)}{0.01823} =\frac{\ln 1.7647}{0.01823} \approx\frac{0.5680}{0.01823}\approx 31.2\text{ yr}\] The population reaches 150,000 around 2041.

Doubling time: \(t_d = \ln 2/0.01823 \approx 38.0\) years. Population doubles by \(\approx\)2048.

Summit

Schema Navigation

Linear vs. exponential model — identifying from data.

Check successive ratios: \(102{,}000/85{,}000=1.200\). If each decade multiplies population by \(\approx 1.200\), this is exponential. A linear model would instead show constant differences (\(+17{,}000\)/decade).

Long-run comparison: \[\begin{array}{c|c|c} \text{Year} & \text{Exponential} & \text{Linear} \\\hline 2010 & 85{,}000 & 85{,}000 \\ 2020 & 102{,}000 & 102{,}000 \\ 2030 & 122{,}400 & 119{,}000 \\ 2040 & 146{,}900 & 136{,}000 \\ 2060 & 211{,}400 & 170{,}000 \end{array}\]

By 2060, the two models differ by over 40,000 people. Infrastructure planning based on the wrong model produces catastrophic under- or over-building. The choice of model — linear vs. exponential — is not a mathematical technicality. It is a policy decision with real consequences.

Example 1.6 Drug Elimination: Half-Life

A medication has a half-life of 6 hours. A patient receives 400 mg at \(t=0\). Find the model, the continuous decay rate, and when the concentration drops below 25 mg.

Base Camp

Schema Navigation

Step 1 — Find \(k\) from the half-life. \(t_{1/2}=6\) hr: \(\ln 2/|k|=6 \Rightarrow |k|=\ln 2/6\approx 0.1155\). Since decay, \(k=-0.1155\).

Step 2 — Write the model. \(Q(t)=400\,e^{-0.1155t}\) mg.

Verify: \(Q(6)=400\,e^{-0.693}=400(0.5)=200\) mg. ✓

Mid-Mountain

Schema Navigation

\(Q(t)=400\,e^{-0.1155t}\).

When does \(Q\) reach 25 mg? \[400\,e^{-0.1155t}=25 \;\Rightarrow\; e^{-0.1155t}=0.0625 \;\Rightarrow\; t=\frac{\ln(0.0625)}{-0.1155}=\frac{-2.773}{-0.1155}\approx 24\text{ hr}\]

This is exactly 4 half-lives: \((1/2)^4=1/16\) of 400 mg \(= 25\) mg. ✓

\[\begin{array}{c|c|c} t \text{ (hr)} & \text{Half-lives} & Q(t) \text{ (mg)} \\\hline 0 & 0 & 400 \\ 6 & 1 & 200 \\ 12 & 2 & 100 \\ 18 & 3 & 50 \\ 24 & 4 & 25 \end{array}\]

Summit

Schema Navigation

Steady-state under repeated dosing.

Suppose the patient receives 400 mg every 24 hours. After each dose, the previous dose has decayed to \((1/2)^4=1/16\) of its original amount (25 mg, as computed). The trough \(Q^*\) (concentration just before each dose) satisfies: \[Q^* + 400 = Q^* \cdot e^{0.1155\times 24} \;\Rightarrow\; \frac{Q^*+400}{Q^*}=e^{2.772}=16 \;\Rightarrow\; Q^*+400=16Q^* \;\Rightarrow\; Q^*=\frac{400}{15}\approx 26.7\text{ mg}\]

The steady-state trough is 26.7 mg. The peak (immediately after each dose) is \(26.7+400=426.7\) mg. The dosing interval was calibrated to the half-life — confirming that half-life is the key parameter for designing dosing schedules.

    YES → Identify input \(x\) and output \(y\). State what each represents and its units.
    NO / NEXT → Re-read. Every function problem has something going in and something coming out. Find them first.
  2. 2Is there exactly one output for every input? (Vertical Line Test)
    YES → This IS a function. Proceed to Step 3.
    NO / NEXT → Not a function as stated. Describe why.
  3. 3What TYPE of function is this?
    YES → LINEAR: identify slope \(m\) and intercept \(b\); interpret economically. EXPONENTIAL: identify base \(a\) (or rate \(k\)) and initial value \(Q_0\). LOG: \(\ln x\) is the inverse of \(e^x\).
    NO / NEXT → If the type is unclear: check differences (linear) or ratios (exponential).
  4. 4What is the realistic DOMAIN?
    YES → State domain in interval notation. Check: can input be negative? Zero? For \(\ln x\): domain is \(x>0\) only.
    NO / NEXT → Economic domains are often more restrictive than mathematical ones.
  5. 5For exponential problems: am I solving for a time or predicting a quantity?
    YES → QUANTITY: evaluate \(Q_0 e^{kt}\) at the given \(t\). TIME: set \(Q_0 e^{kt}=\text{target}\), divide by \(Q_0\), take \(\ln\), divide by \(k\).
    NO / NEXT → Always check the sign of \(k\): positive = growth, negative = decay.
Common Errors

Mistakes that appear on every exam

  1. \(f\) is the relationship; \(f(x) = 3x+2\) is one way to express it. When the domain is restricted, the formula alone does not define the function.

  2. Writing “domain: all real numbers” for a production quantity is wrong. Negative production is impossible. For \(\ln x\): the domain is \(x>0\) only.

  3. Revenue \(R(q) = D(q)\cdot q\) uses the demand function — not a fixed price.

  4. \(C(q) = FC + VC\cdot q\) for a linear cost, not just \(VC\cdot q\).

  5. If annual growth is 15%, then \(a=1.15\) but \(k=\ln(1.15)\approx 0.140\), not \(0.15\).

  6. Take \(\ln\) of both sides: \(kt=\ln b\). You cannot “cancel” \(e\) by dividing.

  7. Doubling time is \(t_d=\ln 2/k\). At \(k=0.08\): \(t_d\approx 8.66\) yr, not \(1/0.08=12.5\) yr.
